# Summer Internship Program 2026

This repository contains the assignments, design implementations, and verification tasks completed during the Summer Internship Program 2026 organized by the Department of Electronics and Communication Engineering, TKM College of Engineering, in collaboration with OPSILIN Semiconductor Pvt. Ltd., Stem A Chip, and IEEE CASS SBC TKMCE.

## Internship Focus Areas

- Digital Design
- RTL Development
- Design Verification
- FPGA-Based Design
- Memory Design
- AMBA APB Protocol
- SystemVerilog Verification Methodology

## Repository Structure

### Day 1
- Basic Digital Design Implementations
- Combinational Logic Circuits

### Day 2

- Sequential Circuit Design
- Simulation and Verification

### Day 3

### AMBA APB Protocol
- APB Master Design
- Interface-Based Verification Environment

- Waveform Analysis using EPWave
