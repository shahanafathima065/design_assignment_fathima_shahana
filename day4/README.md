# Block Memory Generator

## 1. System Overview

This project implements a Block Memory Generator using Verilog HDL and Xilinx Vivado. The design performs memory write and read operations using address-based access. The memory consists of 8 locations, each capable of storing 8-bit data. The design supports synchronous memory operations and active-low reset functionality.

---

## 2. Objective

To design, implement, simulate, and synthesize a Block Memory Generator and verify its read/write functionality using a Verilog HDL testbench.

---

## 3. Introduction

Block RAM (BRAM) is a dedicated memory resource available inside FPGA devices. Unlike memories implemented using LUTs and registers, BRAM utilizes specialized memory blocks present in FPGA hardware, resulting in efficient memory implementation with reduced logic utilization.

Xilinx Vivado provides memory generation capabilities that allow designers to implement configurable RAM structures for data storage and retrieval applications.

In this project, a Block Memory Generator was implemented, simulated, and synthesized to verify memory write and read operations.

## 5. Theory

A Block Memory Generator creates memory blocks that store and retrieve data based on address locations.

The memory supports:

- Data Storage
- Data Retrieval
- Address-Based Access
- Synchronous Read and Write Operations
- Reset Functionality

The implemented memory contains 8 locations addressed using a 3-bit address bus. Each memory location stores 8-bit data.

## 8. Working Principle

The Block Memory Generator performs memory operations based on address and control signals.

### Write Operation

When the write enable signal is HIGH:

```verilog
wr_enb = 1;
mem[wr_ad] <= d_in;
```

### Read Operation

When the write enable signal is LOW:

```verilog
wr_enb = 0;
d_out <= mem[rd_add];
```

The output displays the data stored at the selected memory location.
